# 🖱️ Mouse Click Simulator — 鼠标点击模拟器

一个轻量级 Windows 桌面工具，用于在指定屏幕区域自动执行连续鼠标点击。

---

## 📖 保姆级使用教程（零基础）

下面的每一步都有截图级的文字说明，照做就行。

---

### 🔧 第一步：确认你的电脑已经有 .NET 10 SDK

你说你已经安装了 .NET 10，我们先确认一下它是否正常工作。

1. **按下键盘上的 `Win + R`**（Win 键就是键盘左下角那个 Windows 图标键）
2. 在弹出的"运行"对话框里输入 `powershell`，然后按回车
3. 会弹出一个 **蓝色/黑色的命令行窗口**，这就是 PowerShell
4. 在里面输入下面这行字，然后按回车：

```
dotnet --version
```

5. 如果你看到类似 `10.0.xxx` 的数字，说明一切正常，继续下一步。
   如果报错说"找不到命令"，说明 SDK 没装好，去这里重新下载安装：
   👉 https://dotnet.microsoft.com/download/dotnet/10.0 （选 **SDK**，不是 Runtime）

### 🎮 第四步：使用程序（重点！）

窗口长这样（文字描述）：

```
┌─────────────────────────────────────────┐
│  鼠标点击模拟器                           │
│                                          │
│  ┌─ 目标区域（屏幕坐标）───────────────┐ │
│  │  X: [    0]    Y: [    0]           │ │
│  │  宽度: [  0]   高度: [  0]  [🎯拾取] │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  ┌─ 点击选项 ──────────────────────────┐ │
│  │  频率(次/秒): [  10]  最大次数: [ 0]│ │
│  │  ☐ 随机抖动     鼠标按键: [左键 ▾] │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  [ ▶ 开始 ]    [ ■ 停止 ]               │
│                                          │
│  就绪                                    │
│  快捷键：F9 = 暂停/继续 | Esc = 停止    │
└──────────────────────────────────────────┘
```

下面逐个解释每个参数：

---

#### 📍 目标区域

这部分告诉程序 **"点哪里"**。

| 参数 | 是什么意思 | 举例 |
|------|-----------|------|
| **X** | 从屏幕**左边缘**到目标点的水平距离（像素） | 屏幕正中间大约是 960 |
| **Y** | 从屏幕**上边缘**到目标点的垂直距离（像素） | 屏幕正中间大约是 540 |
| **宽度** | 点击区域的宽度。填 0 就只点一个固定的点 | 填 100 就会在 100 像素宽的范围内点 |
| **高度** | 点击区域的高度。填 0 就只点一个固定的点 | 填 100 就会在 100 像素高的范围内点 |

> **🤔 "我不知道坐标是多少怎么办？"**
>
> 点 **"🎯 拾取坐标"** 按钮！程序会倒计时 3 秒，你赶紧把鼠标移到你想点击的位置，
> 3 秒后程序会自动把那个位置的坐标填到 X 和 Y 里。

---

#### ⚙️ 点击选项

这部分告诉程序 **"怎么点"**。

| 参数 | 是什么意思 | 建议值 |
|------|-----------|--------|
| **频率 (次/秒)** | 每秒钟点击多少次。数字越大点得越快 | 新手先设 5~10，别一上来就 1000 |
| **最大次数** | 点够这个数就自动停。填 0 表示一直点不停 | 测试的时候建议先填 20，试试效果 |
| **随机抖动** | 打勾后，每次点击的位置会在区域内随机偏移，看起来更像真人操作 | 如果宽度/高度 > 0 再勾 |
| **鼠标按键** | 左键 / 右键 / 中键 | 一般都是左键 |

---

#### ▶️ 控制按钮

| 按钮 | 作用 |
|------|------|
| **▶ 开始** | 开始自动点击（按下后按钮会变灰，防止重复点击） |
| **■ 停止** | 立刻停止所有点击 |

---

#### ⌨️ 键盘快捷键（很重要！）

因为程序运行起来会抢走你的鼠标，你可能没法用鼠标去点"停止"按钮。
所以你需要用 **键盘** 来控制：

| 按键 | 效果 | 什么时候用 |
|------|------|-----------|
| **F9** | 暂停 / 继续 / 启动 | 随时按都行。点击中按一下暂停，再按一下继续 |
| **Esc** | 立刻停止 | **最重要的按键！** 发现不对劲立刻按 Esc |

> 💡 这两个快捷键是 **全局** 的——即使你切换到了别的窗口，按 F9 / Esc 照样有效。

### 📝 第五步：实战演练（手把手）

我们做一个最简单的测试：**让程序在桌面上自动点击 10 次**。

1. **打开程序**（第三步的方法）
2. **点击 "🎯 拾取坐标" 按钮**
3. 你会看到状态栏开始倒计时：`请将鼠标移到目标位置… 3s → 2s → 1s`
4. **在倒计时结束前，把鼠标移到你想点击的位置**（比如桌面空白处）
5. 倒计时结束后，X 和 Y 会自动填好
6. 把 **"最大次数"** 改成 `10`（这样点 10 次就自动停，不会失控）
7. **频率** 保持 `10`（每秒 10 次）
8. 点 **"▶ 开始"**
9. 你会看到鼠标自动跳到那个位置开始点击，状态栏显示 `运行中… 已点击 X 次`
10. 点到 10 次后自动停止，状态栏显示 `完成！共点击 10 次`

**恭喜！** 🎉 你已经成功完成了第一次自动点击。

### ❌ 常见问题

#### Q：双击 exe 没反应 / 报错？
A：可能是 .NET 10 Runtime 没装好。在 PowerShell 里运行这个命令看版本：
```powershell
dotnet --list-runtimes
```
需要看到 `Microsoft.WindowsDesktop.App 10.0.x` 这行。如果没有，重新安装 .NET 10 SDK。

#### Q：程序跑起来鼠标乱飞，我控制不了了！
A：**按 Esc！** 这是紧急停止键，任何时候都有效。

#### Q：频率设了 1000 但感觉没那么快？
A：正常。Windows 系统消息处理有上限，实际最高频率大约 500~800 次/秒，取决于你的电脑性能。

#### Q：想点击的区域在另一个程序上面，但模拟器窗口挡住了？
A：模拟器窗口虽然置顶，但可以拖到屏幕角落。用 **F9** 快捷键启动/暂停，不需要看到模拟器窗口。

#### Q：我想发送到别人电脑上用，但对方没装 .NET？
A：用这个命令打包成独立 exe（对方不需要装任何东西）：
```powershell
cd D:\agy\MouseClickSimulator
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```
打包后的 exe 在 `bin\Release\net10.0-windows\win-x64\publish\` 文件夹里，大约 60~80 MB。
